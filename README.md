# F1 Reflex 🏎️⚡

**F1 Reflex** is a simple reflex-based browser game inspired by Formula 1.
The goal is to test and improve your reaction time by responding quickly to on-screen events.

Repository: https://github.com/fdehech/F1_Reflex

---

## 🧠 Features

- Reflex and reaction-time based gameplay
- Simple and clean UI
- Runs directly in the browser
- No external libraries or frameworks

---

## 🚀 Getting Started

### Prerequisites
- Any modern web browser (Chrome, Firefox, Edge, etc.)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/fdehech/F1_Reflex.git
```

2. Navigate to the project folder:
```bash
cd F1_Reflex
```

3. Open `index.html` in your browser.

Or run a local server:
```bash
python -m http.server
```
Then visit:
```
http://localhost:8000
```

---

## 🎮 How to Play

1. Open the game in your browser.
2. Wait for the visual signal.
3. React as fast as possible when prompted.
4. Your reaction time will be measured.

Try to beat your best score! 🚀
